================================================================
MC 服务器管理器 v0.2  使用说明
================================================================

一个 Windows 上的 Minecraft 服务器管理工具（图形界面）。
主要功能：扫描本机服务端 → 初始化新服务端（下核心 / 下模组）
→ 启停并看控制台 → 改 server.properties → 备份/恢复存档
→ 装/删模组 → 分析崩溃日志 → 换主题。

不是命令行工具，打开点按钮就能用；但安装前需要 Python 和
PySide6（安装程序可以帮你装好）。

================================================================
一、安装
================================================================

【方式 A：使用安装程序（推荐）】

  1. 把安装包（MCSM_v0.2_安装包.zip）解压到任意位置；
  2. 双击  安装.bat  ；
  3. 在窗口中确认/修改“安装目录”，按需勾选：
       [√] 如果本机没有 Python，自动下载安装 Python 3.12
       [√] 安装 PySide6 界面库（约 100MB，需要联网）
       [√] 创建桌面快捷方式
       [√] 安装完成后立即启动
  4. 点“开始安装”，等进度跑完即可。

  说明：
    · 安装 Python 是“当前用户安装”，不需要管理员权限；
    · 只会在本机没有 Python 3.9+ 时安装；已有 Python 会自动使用；
    · PySide6 已安装则跳过；下载失败会自动换国内镜像重试；
    · 安装目录默认在：C:\Users\你的用户名\AppData\Local\MC服务器管理器
      （可以自己选，例如 D:\MC服务器管理器）。

【方式 B：手动安装】

  1. 安装 Python 3.9 或更高版本：
       https://www.python.org/downloads/
       安装时勾选 “Add Python.exe to PATH”。
  2. 安装 PySide6：
       命令行执行：  python -m pip install PySide6
       （如果网络慢，加国内镜像：python -m pip install PySide6 -i https://pypi.tuna.tsinghua.edu.cn/simple）
  3. 双击 start_manager.bat 启动。

【验证安装】

  双击桌面快捷方式，或安装目录里的 start_manager.bat。
  出现主窗口即成功。如果提示缺少 Python / PySide6，按提示安装后再试。

================================================================
二、第一次使用
================================================================

  1. 选择总目录
     点顶部『扫描』，选择存放各个服务器的总文件夹
     （例如 D:\MCServers）。
     软件会扫描每个子文件夹，识别：MC 版本、加载器、存档、region 数。

  2. 初始化服务端（新服）
     选中一个地图 → 点『初始化服务端』：
       版本   自动识别（可改）
       加载器 Paper / Fabric / Forge / NeoForge
       Java   自动扫描，也可手动选
       内存   默认 1G~4G
       模组   选 Fabric 时可直接挑优化模组
     点开始后会自动：下核心 → 下模组 → 生成 server.properties
     → 生成 eula.txt → 生成 run.bat。

  3. 启动
     选中服务器 → 点『启动』；右下角控制台可看实时日志、发指令。
     也可以直接双击服务器目录里的 run.bat。

  4. 修改配置 / 备份 / 模组
     选中服务器 → 点『服务器配置』，里面有：
       server.properties、核心、模组、模组配置、备份、启动设置。

================================================================
三、加载器怎么选
================================================================

  Paper    插件服。玩家用原版客户端就能进，不用装任何东西。
           想装插件（权限/回溯/领地）选它；对固定版本地图最安全。

  Fabric   模组服。轻量，优化模组生态最好。

  Forge    模组服。老牌，老整合包常用。

  NeoForge 模组服。Forge 的新分支，1.20.2+ 才有。

  · Paper 官方只维护较新版本；旧版本（如 1.21.3/1.21.4，
    甚至 1.7.10）官方标记为 unsupported，但 fill 站仍能下载，
    本软件会自动处理。太老的版本官方不再修 bug / 补安全漏洞。
  · 地图介绍说“不兼容 Fabric/Forge”时，指的是服务端别用模组加载器；
    玩家客户端装 Fabric 优化模组不受影响。

================================================================
四、常用功能
================================================================

【更换核心 / 更新加载器】
  服务器配置 → 核心：
    · “下载并更换”可以换加载器（存档、模组、配置全部保留）；
    · “更新加载器”只换核心文件；
    · Fabric 服更新加载器时可勾选“同时更新 Fabric API”，
      旧版会改名 .old 留底；
    · “删除核心”只删核心 jar，存档/模组/配置不动。

【模组管理】
  服务器配置 → 模组，或主界面右键 →『模组管理』：
    · 从 Modrinth / CurseForge 搜索安装；
    · 启用/禁用（改后缀 .jar.disabled，不删文件）；
    · 检查更新（按文件哈希查，准确率高）。

【备份与恢复】
  服务器配置 → 备份，或右键 →『备份管理』：
    · 只备份存档（world / 维度 / 重要配置），不备份整个服务端；
    · 恢复时不会套娃；删除备份留残骸会自动提示。

【日志诊断】
  点『分析日志』：离线规则匹配 latest.log，
  每条报错给“为什么 / 怎么修 / 日志原文 / 位置”。
  点『导出报错诊断』可以把日志和配置打包，方便发给别人排查。

【显示与主题】
  显示设置 → 列表 / 外观主题：
    · 图标视图与表格视图、4 种排序、拖动排序；
    · 10 个预设配色、字体、字号、粗体、背景图；
    · “选中与悬停效果”：页签字色、列表字色、选中竖杠、悬停注释。

【统一搬迁 / 导入地图】
  · 『统一搬迁』把散落的地图批量复制/移动到一个总目录；
  · 『导入地图』把一个地图文件夹按“版本-地图名”结构导入；
  · 两者都在后台线程执行，大存档不会卡界面。

================================================================
五、常见问题
================================================================

Q1：提示缺少 Python 或 PySide6？
    A：请重新双击 安装.bat，会自动帮你修复环境。
       如果你想手动安装，可执行：
         python -m pip install PySide6
       国内网络慢可以加镜像：
         python -m pip install PySide6 -i https://pypi.tuna.tsinghua.edu.cn/simple

Q1.1：双击安装.bat 提示“路径的形式不合法”？
    A：这是因为你把安装目录选成了盘符根目录（比如 D:\ 或 C:\）。
       在 Windows 下直接装到盘符根目录容易引发权限和路径错误，
       请建一个子文件夹，例如 D:\MC服务器管理器 或 D:\MCServerManager。

Q2：安装 Paper 时提示某个版本装不了？
    A：Paper 官方只维护较新版本；旧版本请让软件自动走 fill 站
       （新版已经自动处理）。如果 fill 站也没有，改选 Fabric。

Q3：更新加载器后 Fabric API 还是旧版？
    A：新版已支持“更新加载器时同时更新 Fabric API”（默认勾选）。
       也可以到服务器配置 → 模组 → “更新 Fabric API”单独更新。

Q4：启动服务器提示端口被占用？
    A：服务器配置里可以改 server-port；软件在启动前也会检查端口冲突。

Q5：Java 版本不对，服务端起不来？
    A：软件会按 MC 版本推荐 Java（1.20.1→17，1.21.x/26.1/26.2→21，
       26.3→25）。在初始化的“Java”处可以手动选。

Q6：扫描后加载器显示不对？
    A：新版按 jar 内部识别，不会只看文件名。
       如果仍不对，确认“服务端目录”下确实是那个核心 jar；
       点『重新扫描』即可。

Q7：为什么会有两份程序目录？
    A：不要把程序复制到多个地方使用。只保留一个安装目录，
       否则会出现“改了 A 却运行 B”的情况。

Q8：配色被改了？
    A：显示设置 → 外观主题 → 选“恢复默认”，或直接选喜欢的预设。
       主题保存在安装目录的 theme.json，软件不会再改它。

Q9：误删了存档怎么办？
    A：软件删除服务器/核心前都会确认；备份目录在服务器的
       backups 下。重要存档建议定期手动复制一份到别的盘。

Q10：怎么卸载？
    A：双击安装目录里的 卸载.bat。
       可选择只删程序、保留配置；也可以连同 servers.json /
       theme.json / sources.json 一起删除。

六、配置文件与目录
================================================================

  安装目录/
    mcserver/            程序源码
    icons/               图标
    start_manager.bat    启动入口
    安装.bat             安装程序（安装包内）
    卸载.bat             卸载程序
    servers.json         服务器列表、自定义排序、显示设置
    theme.json           主题与配色
    sources.json         模组下载源、CurseForge Key
    mc_versions_cache.json  MC 版本缓存

  服务器总目录（自己选，例如 D:\MCServers）/
    1.21.3-地图名/
      ├── server/ 或地图文件
      ├── world 等存档目录
      ├── mods/ 或 plugins/
      ├── server.properties
      └── run.bat

================================================================
七、注意事项
================================================================

  · 服务器正在运行时不要更新核心/删核心/改核心文件，
    请先停止服务器；文件被占用会导致更新失败。
  · 升级软件时直接运行新安装包覆盖安装即可，
    servers.json / theme.json / sources.json 会保留。
  · 删除服务器会删除整个服务器文件夹（含存档），操作前会确认；
    重要数据请先备份。
  · 网络下载（Paper/Fabric/Forge/Modrinth/CurseForge）需要联网；
    国内网络不稳定时软件会自动重试或切换镜像。
  · 本软件只负责管理，不附带 Minecraft 服务端本体和 Java。
