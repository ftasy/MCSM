v2.0.4  推荐适配检测真实生效（ModernFix 分流）/ 搜索不再弹镜像源（2026-10-28）
----------------------------------------------------------------

【1. ModernFix 按 MC 版本分流（1.21.5+ 用社区版）】
  · 1.21.5 及以后：原版 ModernFix 停更没有适配版本，
    自动改装社区版 ModernFix-mVUS（支持小版本更新的 fork），
    适配检测、下载、Modrinth 链接全部指向社区版项目。
  · 1.21.4 及更早：继续用原版 ModernFix。
  · 推荐列表的『适配检测中…』不再卡死：检测结果真实生效，
    26.3 + fabric 下 ModernFix 显示版本兼容、可正常勾选安装。

【2. 修复『每次搜索都弹镜像源选择窗』】
  · 根因一：官方 CurseForge 源没配 API Key 时，每次搜 CF 都被
    『官方 CF 需要 API Key』拦住 —— 现在自动退回 MCIM 镜像
    （免 key），只有镜像也不通才提示；下载/适配探测同步生效。
  · 根因二：模组管理页『镜像源设置』曾是非模态窗口，关不掉会
    一直挂在屏幕上，看着像“每次搜索都弹窗” —— 改回模态
    （关掉才返回），不再残留。

v1.6.1  内存单位动态切换与智能换算（GB / MB）（2026-10-26）
----------------------------------------------------------------

【初始化界面（创建服务器）】
  · 「最小内存 / 最大内存」输入框旁新增单位下拉框（G / MB，默认 G）。
  · G 模式：允许一位小数（0.5 步进），范围 1.0 ~ 64.0 G，
    默认 1.0G / 4.0G。
  · MB 模式：整数，范围 512 ~ 65536 MB，步长 512，
    默认 1024 / 4096。
  · 智能换算：
      - MB → G：除以 1024，整除显示整数（3072 → 3），
        除不尽保留一位小数（3584 → 3.5）。
      - G → MB：乘以 1024 取整（3.5 → 3584）。
  · 创建时统一转为整数 MB 写入服务器配置（如 xms=1024、xmx=4096）。

【服务器配置 -> 启动设置】
  · 内存输入框旁同样有 G / MB 单位下拉框。
  · 智能回显：读取已存配置时，数值能被 1024 整除（如 4096）
    自动以 G 展示（4.0G）；除不尽（如 3584）自动切到 MB 展示。
  · 保存时统一按当前单位换算成整数 MB，写入 servers.json，
    run.bat 保持 -Xms4096M 格式。
  · Aikar 同步（最大=最小）改为按整数 MB 桥接，两个框单位
    不一致也不会串数值。

【数据持久化】
  · servers.json 里 xms / xmx 永远存整数 MB（如 4096），
    绝不存带 "G" 的字符串或小数；主界面启动读取时永远是
    安全可用的整数 MB。

【服务器核心安装】
  · Paper 下载全面改用官方 Fill v3 接口。
    原 api.papermc.io/v2 已整体下线（实测全部返回 410），旧代码会先失败再回退。
  · Paper 旧版本（1.21.3 / 1.21.4，甚至 1.7.10 等）在 fill 站仍可下载，
    软件会自动处理；这些版本被官方标记为 UNSUPPORTED，不再修 bug / 补安全漏洞。
  · Fabric、Paper、Forge、NeoForge 的安装和加载器更新全部重新测试。
  · 修复 Forge 加载器更新永远提示“查不到版本”的问题。
  · 修复 Paper 加载器更新因参数名过旧而直接报错的问题。
  · Forge / NeoForge 更新会自动寻找可用的 Java；服务器配置里保存的 Java 也会带过去。
  · 更新加载器时（Fabric 服）可选“同时更新 Fabric API 前置模组”，默认勾选；
    旧版 Fabric API 会改名成 .old 留底，避免新旧两个版本同时加载。

【扫描与识别】
  · 加载器识别改为读取 jar 内部特征，不再只看文件名：
      - Paper 装成 server.jar 也能正确识别为 paper；
      - 原版 server.jar 不会再被误判成 Paper。
  · 扫描改到后台线程，服务器多、world 大时界面不再卡住；
    扫描过程中切换总目录会自动按新目录重新扫描。
  · 存档选择优先使用 server.properties 里的 level-name，
    并排除 backups 目录，不会再拿备份存档当主存档显示。

【启动 / 搬迁 / 导入】
  · 统一搬迁、拖放导入、工具栏“导入地图”全部改为后台线程，复制大存档不卡界面。
  · 搬迁/导入进行中关闭窗口会先确认，避免留下复制了一半的文件夹。
  · 启动时如果上次的总目录不存在（例如盘符换了），不再弹框卡住，只在状态栏提示。

【界面】
  · 顶部文字按钮新增悬停淡入、按下回弹动画。
  · 移除描边功能，只保留粗体设置。
  · 显示设置里的“PCL 风格”改名为“选中与悬停效果”，相关选项改成更直白的名字。
  · 移除“PCL 龙猫蓝”预设配色。
  · 主题配置损坏（例如颜色字段被写成 false）时自动恢复默认，避免界面异常。

【稳定性 / 清理】
  · 修复通过 Modrinth 下载/更新模组必定失败的问题（下载函数参数不匹配）。
  · 修复“已装 Fabric API 检测不到”的问题（之前扫错了目录）。
  · 修复主题文件中残留旧配色/坏值时界面异常的问题。
  · 修复关闭窗口时，后台服务器进程可能导致程序卡死或闪退的问题：
      定时器现在挂载了父对象；强杀进程后等待 500ms 防止出现僵尸进程。
  · 修复多开备份冲突（改用字典按服隔离）。
  · 修复 `analyze.py` 因旧函数名导致的静默报错。
  · 修复 `loaderup.py` 的正则识别不到新版 `neoforge` 的问题。
  · 修复扫描时网络接口查询报错不提示的问题。
  · 清理死代码 100 余处：重复定义的方法、没有任何入口的功能、
